🚀 ওয়েবসাইটে Publish করুন
আপনার চেঞ্জ সবার কাছে দেখাতে GitHub Token লাগবে (একবারই সেটাপ):
1️⃣ github.com/settings/tokens → "Generate new token"
2️⃣ Token name: ex-rabbi-publish
3️⃣ Repository access → Only select: exrabbi/ex-rabbi
4️⃣ Permissions → Contents: Read and write → Generate token
5️⃣ Token কপি করে নিচে পেস্ট করুন → Save করুন ✅
